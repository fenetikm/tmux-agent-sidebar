The bottom panel's **Git** tab surfaces the git state of the pane's cwd.

## Header

The top rows summarise the pane's branch state.

- **Branch** — current branch name
- **Ahead / behind** — `↑N` / `↓N` counts vs. the configured upstream
- **PR number** — `#123` when [GitHub CLI](https://cli.github.com/) (`gh`) resolves a pull request for the branch; the overlay is a clickable hyperlink in terminals that support OSC 8
- **Diff shortstat** — combined added / deleted line counts and changed file total

## File sections

Changed paths are grouped into three sections, each prefixed with a single-character status and followed by a right-aligned `+added/-deleted` numstat (omitted for untracked entries).

- **Staged** — content already added to the index
- **Unstaged** — tracked files with working-tree changes
- **Untracked** — files the index has never seen

Status letters:

- `A` — added
- `M` — modified
- `D` — deleted
- `?` — untracked

Each section lists up to 10 entries and collapses the rest into a `+N more` row.

Git data is refreshed from a background polling thread, so interaction with the sidebar stays snappy even in repositories with slow git operations.

## Opening the PR

The PR number renders as a terminal hyperlink and opens on a plain left-click, using `open` / `xdg-open` or whatever `@sidebar_link_click_command` names. See [Custom panel](/tmux-agent-sidebar/features/custom-panel/#links) for why both the escape sequence and the click handler are there.

## Hiding the tab

```tmux
set -g @sidebar_show_git_tab off
```

The tab leaves the tab bar, `Shift+Tab` cycles what remains, and any pane parked on Git moves to the next tab that exists. See [Activity log](/tmux-agent-sidebar/features/activity-log/#hiding-the-tab) for the matching `@sidebar_show_activity_tab`, and what happens when every tab is off.
